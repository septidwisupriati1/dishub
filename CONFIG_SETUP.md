## Environment Setup

### Initial Setup

1. **Copy `.env.example` to `.env`:**
```bash
cp .env.example .env
```

2. **Generate Application Key:**
```bash
php artisan key:generate
```

3. **Update Database Configuration** in `.env`:
```
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=antrean_uji_kendaraan
DB_USERNAME=root
DB_PASSWORD=
```

4. **Run Migrations:**
```bash
php artisan migrate
```

5. **Seed Database:**
```bash
php artisan db:seed
```

### Environment Variables Explanation

#### Application Settings
```env
APP_NAME=KIR Antrean              # Application name
APP_ENV=local                      # Environment: local, staging, production
APP_KEY=base64:...                # Generated by php artisan key:generate
APP_DEBUG=true                     # Debug mode (false in production!)
APP_URL=http://localhost/kir-antrean  # Base application URL
```

#### Logging
```env
LOG_CHANNEL=stack                  # Logging channel (stack, single, daily)
LOG_LEVEL=debug                    # Log level: debug, info, notice, warning, error
ENABLE_AUDIT_LOG=true              # Enable audit logging
LOG_API_REQUESTS=true              # Log API requests
```

#### Database
```env
DB_CONNECTION=mysql                # Database type (mysql, pgsql, sqlite)
DB_HOST=127.0.0.1                 # Database host
DB_PORT=3306                       # Database port
DB_DATABASE=antrean_uji_kendaraan  # Database name
DB_USERNAME=root                   # Database user
DB_PASSWORD=                       # Database password
```

#### Cache & Sessions
```env
CACHE_DRIVER=file                  # Cache driver (file, redis, memcached)
SESSION_DRIVER=file                # Session driver
SESSION_LIFETIME=120               # Session timeout in minutes
```

#### Queue & Broadcasting
```env
QUEUE_CONNECTION=sync              # Queue driver (sync, database, redis)
BROADCAST_DRIVER=log               # Broadcasting driver
```

## Configuration Files

### Core Configuration Files

#### 1. `config/app.php` - Application Configuration
```php
'name' => env('APP_NAME', 'KIR Antrean'),
'env' => env('APP_ENV', 'production'),
'debug' => env('APP_DEBUG', false),
'url' => env('APP_URL', 'http://localhost'),
'timezone' => 'Asia/Jakarta',
'locale' => 'id',
'providers' => [...],
'aliases' => [...]
```

**Key Settings:**
- `timezone`: Set to `Asia/Jakarta` for Indonesia
- `locale`: Set to `id` for Indonesian language
- `debug`: Must be `false` in production

#### 2. `config/database.php` - Database Configuration
```php
'default' => env('DB_CONNECTION', 'mysql'),
'connections' => [
    'mysql' => [
        'driver' => 'mysql',
        'host' => env('DB_HOST', '127.0.0.1'),
        'port' => env('DB_PORT', 3306),
        'database' => env('DB_DATABASE', 'laravel'),
        'username' => env('DB_USERNAME', 'root'),
        'password' => env('DB_PASSWORD', ''),
    ],
],
'migrations' => 'migrations',
```

**Important Settings:**
- `connection`: Default is MySQL
- `strict`: Laravel query builder strictness mode
- `engine`: Use `InnoDB` for production

#### 3. `config/sanctum.php` - API Authentication
```php
'stateful' => explode(',', env('SANCTUM_STATEFUL_DOMAINS', 'localhost,127.0.0.1')),
'expiration' => env('SANCTUM_EXPIRATION', 1440),
'middleware' => [
    'verify_csrf_token' => App\Http\Middleware\VerifyCsrfToken::class,
    'encrypt_cookies' => App\Http\Middleware\EncryptCookies::class,
],
```

**Configuration:**
- `stateful`: Domains allowed for stateful API calls
- `expiration`: Token expiration time in minutes (1440 = 24 hours)

#### 4. `config/auth.php` - Authentication Configuration
```php
'defaults' => [
    'guard' => 'web',
    'passwords' => 'users',
],
'guards' => [
    'web' => [
        'driver' => 'session',
        'provider' => 'users',
    ],
    'api' => [
        'driver' => 'token',
        'provider' => 'users',
        'hash' => false,
    ],
],
'providers' => [
    'users' => [
        'driver' => 'eloquent',
        'model' => App\Models\User::class,
    ],
],
'passwords' => [
    'users' => [
        'provider' => 'users',
        'table' => 'password_reset_tokens',
        'expire' => 60,
        'throttle' => 60,
    ],
],
```

#### 5. `config/cors.php` - CORS Configuration
```php
'paths' => ['api/*'],
'allowed_methods' => ['*'],
'allowed_origins' => ['*'],
'allowed_origins_patterns' => [],
'allowed_headers' => ['*'],
'exposed_headers' => [],
'max_age' => 0,
'supports_credentials' => false,
```

**For Production:**
```php
'allowed_origins' => [
    'https://yourdomain.com',
    'https://app.yourdomain.com',
],
'allowed_methods' => ['GET', 'POST', 'PUT', 'DELETE', 'OPTIONS'],
```

#### 6. `config/cache.php` - Cache Configuration
```php
'default' => env('CACHE_DRIVER', 'file'),
'stores' => [
    'file' => [
        'driver' => 'file',
        'path' => storage_path('framework/cache/data'),
    ],
    'redis' => [
        'driver' => 'redis',
        'connection' => 'cache',
    ],
],
'prefix' => env('CACHE_PREFIX', 'kir_antrean_'),
```

#### 7. `config/mail.php` - Mail Configuration
```php
'default' => env('MAIL_MAILER', 'smtp'),
'from' => [
    'address' => env('MAIL_FROM_ADDRESS', 'hello@example.com'),
    'name' => env('MAIL_FROM_NAME', 'KIR Antrean'),
],
'mailers' => [
    'smtp' => [
        'host' => env('MAIL_HOST'),
        'port' => env('MAIL_PORT'),
        'encryption' => env('MAIL_ENCRYPTION'),
        'username' => env('MAIL_USERNAME'),
        'password' => env('MAIL_PASSWORD'),
```

## Database Configuration

### MySQL Setup

#### 1. Create Database
```sql
CREATE DATABASE antrean_uji_kendaraan CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

#### 2. Database User (for production)
```sql
CREATE USER 'kir_user'@'localhost' IDENTIFIED BY 'strong_password_here';
GRANT ALL PRIVILEGES ON antrean_uji_kendaraan.* TO 'kir_user'@'localhost';
FLUSH PRIVILEGES;
```

#### 3. Update `.env`
```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=antrean_uji_kendaraan
DB_USERNAME=kir_user
DB_PASSWORD=strong_password_here
```

#### 4. Run Migrations
```bash
php artisan migrate
```

#### 5. Seed Database
```bash
php artisan db:seed
```

### Database Optimization

#### Add Indexes
```sql
-- Indexes are already created by migrations
-- Check with:
SHOW INDEXES FROM queues;

```

#### Backup Database
```bash
# Using mysqldump
mysqldump -u root antrean_uji_kendaraan > backup_$(date +%Y%m%d_%H%M%S).sql

# Using Laravel
php artisan backup:run
```

#### Restore Database
```bash
# Using mysqldump
mysql -u root antrean_uji_kendaraan < backup_20260505_100000.sql

# Using Laravel
php artisan backup:restore
```

## WhatsApp Integration

### Configuration in `.env`

```env
# Provider selection
WHATSAPP_PROVIDER=twilio  # twilio, fonnte, ultramsg, wablas

# Common settings
WHATSAPP_API_KEY=your_api_key
WHATSAPP_API_SECRET=your_api_secret
WHATSAPP_PHONE_NUMBER=+6281234567890
```

### Provider-Specific Setup

#### Twilio
```env
WHATSAPP_PROVIDER=twilio
TWILIO_ACCOUNT_SID=your_account_sid
TWILIO_AUTH_TOKEN=your_auth_token
WHATSAPP_PHONE_NUMBER=whatsapp:+1234567890
```

**Steps:**
1. Go to https://www.twilio.com
2. Sign up and get Account SID and Auth Token
3. Enable WhatsApp integration
4. Get a WhatsApp-enabled phone number

#### Fonnte
```env
WHATSAPP_PROVIDER=fonnte
FONNTE_API_TOKEN=your_api_token
FONNTE_API_URL=https://api.fonnte.com
WHATSAPP_PHONE_NUMBER=6281234567890
```

**Steps:**
1. Go to https://www.fonnte.com
2. Sign up and generate API token
3. Register your WhatsApp Business Account

#### Ultramsg
```env
WHATSAPP_PROVIDER=ultramsg
ULTRAMSG_INSTANCE_ID=your_instance_id
ULTRAMSG_API_TOKEN=your_api_token
WHATSAPP_PHONE_NUMBER=6281234567890
```

#### Wablas
```env
WHATSAPP_PROVIDER=wablas
WABLAS_API_TOKEN=your_api_token
WABLAS_API_URL=https://api.wablas.com
WHATSAPP_PHONE_NUMBER=6281234567890
```

### Testing WhatsApp Configuration

```bash
# Via Artisan command
php artisan tinker

# Inside tinker:
$config = App\Models\WhatsappConfig::where('is_active', true)->first();
$config->provider;  // Should show your provider

POST /api/whatsapp-configs/{id}/test
```

## Security Configuration

### Environment Variables for Security

```env
# Application Security
APP_DEBUG=false                    # MUST be false in production
APP_ENV=production                 # Set to production

# Database Security
DB_PASSWORD=strong_secure_password # Use strong password

# API Security
SANCTUM_EXPIRATION=1440            # Token expiration (24 hours)
SANCTUM_STATEFUL_DOMAINS=yourdomain.com

# CORS Security
# Configure in config/cors.php
```

### HTTPS Configuration

#### In `.env`:
```env
APP_URL=https://yourdomain.com
```

#### In `config/app.php`:
```php
'url' => env('APP_URL', 'https://yourdomain.com'),
'asset_url' => env('ASSET_URL'),
```

#### Force HTTPS (add to `app/Providers/AppServiceProvider.php`):
```php
if ($this->app->environment('production')) {
    \Illuminate\Support\Facades\URL::forceScheme('https');
}
```

### Encryption Configuration

```env
APP_KEY=base64:your_generated_key

# In config/app.php
'cipher' => 'AES-256-CBC',
```

## Rate Limiting

### Configuration in `.env`

```env
RATE_LIMIT_PUBLIC=60,1             # 60 requests per 1 minute for guests
RATE_LIMIT_API=200,1               # 200 requests per 1 minute for API users
RATE_LIMIT_ADMIN=300,1             # 300 requests per 1 minute for admins
```

### Usage

Add to route middleware:
```php
Route::middleware('throttle:public')->group(function () {
    // Public endpoints
});

Route::middleware('throttle:api')->group(function () {
    // API endpoints
});

Route::middleware('throttle:admin')->group(function () {
    // Admin endpoints
});
```

## Troubleshooting

### Common Issues

#### 1. "APP_KEY not set"
```bash
php artisan key:generate
```

#### 2. "SQLSTATE[HY000]: General error"
```bash
# Clear application cache
php artisan cache:clear
php artisan config:clear
```

#### 3. "Access denied for user 'root'@'localhost'"
- Check database credentials in `.env`
- Verify MySQL service is running
- Check MySQL password is correct

#### 4. "WhatsApp config tidak ditemukan"
- Configure WhatsApp provider in dashboard
- Set `is_active = true` for provider
- Test connection via API endpoint

### Maintenance Commands

```bash
# Clear all caches
php artisan cache:clear
php artisan config:clear
php artisan route:clear
php artisan view:clear

# Rebuild caches
php artisan config:cache
php artisan route:cache
php artisan view:cache

# Database maintenance
php artisan migrate:refresh  # DANGEROUS - only in development
php artisan migrate:reset
php artisan migrate:rollback
```
